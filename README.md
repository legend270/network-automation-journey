# Networking & Python Automation Journey

Welcome to my hands-on learning journey combining **Telecommunications Engineering, Computer Networking, Python Programming, and Network Automation**.

As a Telecommunications Engineering student at KNUST, I am developing practical tools that turn networking concepts into useful software projects.

## Projects

### 1. Python Subnet Calculator

A Python tool for calculating network addresses, subnet masks, CIDR prefixes, host ranges, broadcast addresses, and usable hosts.

### 2. Network Device Availability Monitor

A Python project that checks device reachability using ping and displays ONLINE/OFFLINE status.

### 3. Cisco Configuration Generator

A tool that generates Cisco IOS-style configuration commands for hostnames, interfaces, IP addressing, and static routes.

### 4. Network Automation Tool v2.0

A simulation-based project that manages a device inventory, processes predefined Cisco-style commands, organizes results, and generates text reports.

**Note:** The network automation simulation does not connect to live devices. Real-device integration is a future development goal.
