# Cisco Configuration Generator v1.0

A Python-based tool that generates basic Cisco IOS router configurations from user-provided network information.

This project is part of my journey toward Network Automation using Python.

## 🚀 Features

- Generate Cisco router hostname configuration
- Configure multiple router interfaces
- Assign IP addresses and subnet masks
- Automatically add `no shutdown`
- Generate static routes
- Validate IPv4 addresses
- Validate subnet masks
- Save generated configurations to a `.txt` file
- Simple command-line interface

## 🛠️ Technologies Used

- Python 3
- `ipaddress` module
- File handling
- Functions
- Loops
- Conditional statements
- Exception handling
