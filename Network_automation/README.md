# Network Automation Tool v2.0

A Python-based network automation learning project that manages a simulated inventory of routers and switches, processes Cisco IOS-style commands, collects command outputs, and generates a text report.

This project is part of my journey toward Python programming, network engineering, and network automation.

## Features

* Manage multiple network devices through a device inventory.
* Display device names, types, IP addresses, and statuses.
* Process multiple predefined Cisco IOS-style commands.
* Simulate online and offline device handling.
* Collect and organize command outputs.
* Generate a timestamped network report in a text file.
* Summarize device counts and statuses.

## Technologies Used

* Python 3
* Dictionaries and lists
* Functions and loops
* Conditional statements
* File handling

## Commands Simulated

* `show ip interface brief`
* `show ip ssh`
* `show version`

## How to Run

Ensure Python 3 is installed.

Open a terminal in the project directory and run:

```bash
python network_automation.py
```

The program displays the device inventory, processes the predefined commands, summarizes the results, and generates `network_report.txt`.

## Important Note

**This version operates in simulation mode.** Device statuses and command outputs are generated by Python logic; the program does not establish live connections to routers or switches.

The project is intended to develop the programming and data-handling foundations needed for future real-device automation.
